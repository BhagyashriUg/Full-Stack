DOS (Disk Operating System)

  1. What is Operating System?
    2. OS means a platform or media, which is communicate between user and machine.
  2. How to Operate our system?
    3. There are two ways to operate our system.

    GUI

    • Easy to work
    • Low Speed
    • Weak OS
    • Low Security
    • Autorun
    • No Virus Protection
    • No Flexibility
    • e.g. Windows 7, Vista 8, 10, 11

    CLI

    • Hard to Work
    • High Speed
    • Strong OS
    • High Security
    • No Autorun
    • Virus Protected
    • Flexible
    • e.g. DOS, Linux, Unix, Ubuntu,etc.
  3. Types of OS
    4. There are two types of OS(1.Server base OS) (2.Client base OS)

Commands of DOS

  1. exit To Exit from DOS.
  2. cd.. To Back from single directory.
  3. cd/ To Back from all directory of current drive.
  4. d: To change Drive.
  5. dir To show the file and Folder List.
  6. time To show and modify the Time.
  7. date To show and modify the Date.
  8. ver To show the version of current OS.
  9. cls To clear the screen.
  10. color List To show the color List.
  11. copy con (...) To Create File.
  12. ctrl + Z To save and exit from current file.
  13. ctrl + Z To show the content of particular file.
  14. edit (...) To Edit the data of particular file.
  15. ren (old) (new)To rename the file or directory.
  16. del (...) To delete the file.
  17. md (...) To Create the directory.
  18. cd (...) To enter in particular directory.
  19. rd (...) To remove the directory.
  20. tree To show all directory of current drive or directory.
  21. help To show all commands of DOS.
  22. shutdown -s To shut down our system (default time 30s).
  23. shutdown -a To abort the shutdown process.
  24. attrib +s +h (...) To hide particular file or directory.
  25. attrib -s -h (...) To unhide file or directory.
  26. getmac To show the MAC Address.
  27. ipconfig To show the IP Address.
  28. systeminfo To show the all information of System.
  29. copy (...) Location To copy particular file or directory to particular location.
  30. move (...) Location To move particular file or directory to particular location.
  31. copy (...), (...) Location To move multiple files or directory to particular location.
  32. copy (...), (...) Location To copy multiple file or directory to particular location.
  33. copy *.doc (location) To copy all document file to particular location.
  34. move *.doc (location) To move all document file to particular location.
